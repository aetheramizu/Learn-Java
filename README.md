# Learn-Java

This repository contains exercises and case studies from **Memulai Pemrograman Dengan Java** by **Dicoding Academy**. It is organized as a learning archive that covers Java fundamentals, object-oriented programming, standard library usage, and a practical case study.

## About This Repository

The code in this repository is grouped by course module and topic. Each folder typically contains a small Java program or exercise that demonstrates a concept in isolation.

## Learning Topics Covered

### Modul 0 — Introduction
- Hello World program
- Basic project setup and execution

### Modul 1 — Java Basics
- Program structure
- Variables and data types
- Operators
- Control flow and looping
- Strings and basic syntax

### Modul 2 — Object-Oriented Programming
- Functions and methods
- Access modifiers
- Inheritance
- OOP practice examples

### Modul 3 — Common Java Classes
- Collections
- Generics
- Input/output
- Date and time APIs

### Modul 4 — Case Study
- Shape calculator / geometry case study
- Menu-driven console program
- Input handling and calculation logic

## How to Run

Each exercise is usually a small standalone Java program.

1. Open the module or exercise folder you want to study.
2. Locate the `src` directory.
3. Run the `main` class for that exercise from your IDE or build tool.

If you are using an IDE such as IntelliJ IDEA or VS Code, you can usually run the class directly from the editor.

## Prerequisites

- Java Development Kit (JDK)
- A Java-compatible IDE or terminal setup
- Basic familiarity with running Java classes
